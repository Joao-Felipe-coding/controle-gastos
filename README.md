# Controle de Gastos

Aplicativo mobile em React Native com Expo para organizar e acompanhar despesas.

## Requisitos

- Node.js
- npm
- Expo Go ou emulador Android/iOS

## Como executar

```bash
npm install
npm start
```

## Scripts

- `npm start` inicia o Expo
- `npm run android` abre no Android
- `npm run ios` abre no iOS
- `npm run web` abre no navegador
